# RareCloud Homebrew Tap

```sh
brew install rarecloudio/tap/rarecloud
```

Installs the `rarecloud` CLI with the `rcloud` and `rare` aliases.

The formula in this tap is generated and updated automatically by GoReleaser
on every CLI release. Do not edit it by hand. Binaries are hosted at
https://github.com/RareCloudio/rarecloud-cli/releases
